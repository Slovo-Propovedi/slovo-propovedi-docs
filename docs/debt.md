# Технический долг (debt)

Принцип: **каждый срезанный угол записывается в тот же PR**, жёстким форматом. Не «потом вспомним», а «записали сейчас». Перед завершением PR открой этот файл и добавь всё, что не доделал.

Формат записи: `- [ ] <что не доделано> — <где (пути файлов)> — <когда вернуться/контекст>`.
Закрытая запись: `- [x] ...`.

## Документация и согласованность

- [x] **Расхождение версии OpenAPI.** `openAPI.yaml` объявляет `openapi: 3.0.0`, а `README.md` (строки 19, 52) и часть документации называют спецификацию «OpenAPI 3.0.3». Унифицировать: либо обновить `README.md`, либо (если это опечатка) поправить `openapi:` в `openAPI.yaml`. — `openAPI.yaml`, `README.md`, `docs/` — вернуться при ближайшем изменении спецификации/README. — **Закрыто 2026-08-13**: `openAPI.yaml` выровнен до `openapi: 3.0.3` (соответствует README).
- [x] **Расхождение имени образа в командах.** Прямые docker-команды в `README.md` используют тег `docs` (`docker build -t docs .`), а `Makefile` — `slovo-propovedi-docs` (`PROD_IMAGE := slovo-propovedi-docs`). Оба работают (это локальные имена тегов), но лучше унифицировать, чтобы не путать. — `README.md`, `Makefile`, `AGENTS.md` — при следующем изменении документации/команд. — **Закрыто 2026-08-13**: README приведён к `slovo-propovedi-docs` (соответствует Makefile/Dockerfile LABEL).
